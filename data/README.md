# Data

Every file here was generated by the chapter scripts with a fixed random seed.
Run `source("run_all.R")` from the repository root to recreate them.
The datasets are simulated. They do not describe any real experiment.

| File | Chapter | Content |
|---|---|---|
| `ch01_pots.csv` | 1 | Pot experiment with no true fertilizer effect (plants nested in pots) |
| `ch01_corrosion_tidy.csv` | 1 | Corrosion depth of three coatings in tidy format |
| `ch01_dose_data.csv` | 1 | Response to three doses used to compare numeric and factor codings |
| `ch02_resin.csv` | 2 | Tensile strength of four resin formulations (completely randomized design) |
| `ch03_pots.csv` | 3 | Dry mass by dose with variance that grows with the mean |
| `ch04_resin.csv` | 4 | Tensile strength of a control and four formulations |
| `ch05_rcbd.csv` | 5 | Moisture of a snack by drying temperature in six day blocks |
| `ch06_lsq.csv` | 6 | Yield in a 5 x 5 Latin square |
| `ch07_reaction.csv` | 7 | Reaction yield by temperature and catalyst (factorial) |
| `ch07_crop.csv` | 7 | Crop yield by nitrogen rate (quantitative factor) |
| `ch07_mixed.csv` | 7 | Yield by nitrogen rate and variety |
| `ch08_sp.csv` | 8 | Split-plot yield by irrigation (whole plot) and variety (subplot) |
